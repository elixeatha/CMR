# CMR Primer

An interactive single-page primer on cardiac MRI for cardiologists. Open `index.html` in any modern browser; it has no build step or dependencies (Google Fonts are optional).

Tabs:

1. **Acquisition**: T1/T2 relaxation curves, an in-browser k-space demo (FFT), ECG gating, and the core sequences (bSSFP cine, LGE with an interactive TI/inversion-recovery widget, T1/T2 mapping and ECV, perfusion, phase-contrast with a VENC widget, T2*), with artefacts and fixes.
2. **Views & protocol**: step-by-step planning of long-axis, short-axis and 2/3/4-chamber views, plus a typical protocol timeline.
3. **Interpretation**: a systematic approach, approximate normal values, schematic short-axis LGE patterns, mapping values and classic disease appearances.
4. **Seminal papers**: a curated reading list with DOI or PubMed links.
5. **Quiz**: 28 multiple-choice questions with topic filter, score tracker and explanations.

Numbers are rounded teaching values. Use local reference ranges and current guidelines for clinical reporting.
